## 1. 핵심 결정

자사 게임은 디아블로의 빌드 다양성을 메인 축으로 잡고, 메이플의 깊이를 일부 차용하되 천장 시스템으로 좌절을 차단하며, 탕탕특공대의 진행 명확성을 진입 단계에 적용한다.

- ✦ **결정론적 캐릭터 레벨 + 결정론적 강화 + 잭팟 옵션 + 시즌 신화의 4중 구조**
- ✦ **모바일 전용** (단일 API · 모바일 UI)
- **듀얼 실현 (Eternal Realm + Season Realm)** — 베테랑 자산 보존 + 신규 진입 평등
- **데이터 주도 콘텐츠** — 운영팀이 코드 배포 없이 메타 회전

> 캐릭터 레벨(Part 1b)은 결정론적 베이스 진행, 장비 시스템(이 파트·Part 2)은 그 위에 쌓이는 결정론+잭팟 혼합 진행. 두 축이 함께 자라며 챕터 곡선을 따라잡는다.

## 2. 설계 원칙

### 3개 레퍼런스 게임 비교 분석

| 항목 | 탕탕특공대 | 메이플스토리 | 디아블로 |
|---|---|---|---|
| 슬롯 | 6슬롯 정형 | 17+ 슬롯 | 13슬롯 |
| 등급 | 5단계 | 레어→레전더리 | 노말→프라이멀 |
| 핵심 강화 | 융합·별 강화 | 스타포스·잠재·큐브 | 소켓·인챈트·전설효과 |
| RNG 깊이 | 얕음 | 매우 깊음 | 중간 |
| 세트 효과 | 핵심 빌드 축 | 보조 역할 | 스킬 시너지 핵심 |
| 빌드 자유도 | 중간 | 낮음 | 매우 높음 |
| 진행 페이스 | 분 단위 | 월·년 단위 | 시즌제 (3개월) |
| 핵심 훅 | 한 번만 더 융합 | 이번엔 트리플 | 드랍 한 방 |

### 차별화 포지셔닝
- 잭팟의 **즐거움**은 가져오되, 그 부정적 결과(파괴/하락 등)는 도입하지 않는다.
- 베테랑이 자산을 잃지 않으면서도 신규가 평등하게 시즌에 참여할 수 있다.
- 한 번의 코드 배포 없이 운영팀이 시즌 메타를 회전시킬 수 있어야 한다.
