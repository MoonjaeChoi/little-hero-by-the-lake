> 모든 시스템 문서의 UI 와이어프레임을 **통합**. 모바일 iOS 1차, 한 손 플레이 + 44pt + 비폭력 톤. 각 화면별 레이아웃·시각·인터랙션·사운드 정의.

---

## 1. 핵심 결정

- **플랫폼 우선순위**: iOS (세로/가로 모두) → Android → macOS. 9:19.5 (iPhone 12+) 기준 디자인.
- **한 손 플레이**: 가상 조이스틱 좌측 하단 고정 (CLAUDE.md §2). 모든 핵심 인터랙션 한 손으로 가능.
- **터치 타겟 ≥ 44pt** (Apple HIG). 모달의 모든 버튼·슬롯 동일.
- **텍스트 라이브러리**: `UnityEngine.UI.Text` (Legacy). TMP는 URP 셰이더 깨짐 (CLAUDE.md §12).
- **색 채도 60~70%** (파스텔). 너무 쨍한 원색 금지.
- **3 화폐 통합 노출**: 다락방에서만 동시 표시 (별가루 ★ / 무지개 구슬 ✦ / 마법 결정 ◇).
- **인게임은 별가루 ★만 표시**. 무지개 구슬·마법 결정은 메타 자원이라 다락방 전용.
- **장비 카드 6단** (item_drop §7 통합) — 정체성·스탯·강화·주옵션·부옵션·신화.
- **상시 노출 vs 모달**: HUD·다락방 메인은 항상. 강화·인벤토리·지도 등은 모달.

## 2. 설계 원칙

### 2.1. 한 손 플레이

- 가상 조이스틱 좌측 하단 고정 (반경 80px, 안전영역 +16px).
- 자동 공격이라 우측 손은 자유 (가끔 일시정지·이펙트 탭만).
- 모든 모달은 **세로 스크롤** (가로 슬라이드 X — 한 손 엄지로 어려움).
- 닫기 버튼 우측 상단 + 화면 어두운 영역 탭 = 닫기.

### 2.2. 색맹 친화 (Form + Color)

- 데미지·피격 표현은 **색 외에도 형태**로 구분:
  - 일반 적 처치 = 별 흩어짐 ★
  - 미니보스 처치 = 하트 흩어짐 ❤
  - 보스 처치 = 풍선 + 무지개 빛
- 등급(Common~Legendary)은 **색 + 테두리 두께**로 이중 표시.
- 잠금 상태는 **색 + 자물쇠 아이콘** 둘 다.

### 2.3. 비폭력 톤 (CLAUDE.md §2 절대 원칙)

- ❌ 피·시체·잔해·검은 폭발·비명 — **금지**
- ✅ 파티클: 별 ★ / 하트 ❤ / 꽃잎 ❀ / 비눗방울 ◯
- ✅ 사운드: "퐁!" / "쨍-" / "또르륵" / "찰랑~"
- ✅ 보스 사망: 풍선처럼 둥둥 떠올라 사라짐

### 2.4. 한국어 우선

- 모든 노출 텍스트 한국어. 영문 스탯 (HP·DPS) 미노출.
- 어린이 어휘. 한자어·영어 줄임말 ❌.
- 아빠의 메모는 어린이 손글씨 폰트 (별도 폰트 에셋).

### 4.2. 레벨업 연출 (0.8초)

| 시점 | 시각 | 사운드 |
|---|---|---|
| 0.0s | "Lv 12 → 13!" 화면 중앙 (큰 텍스트, 파스텔 노랑) | "쨍-" 따뜻한 종 |
| 0.1s | 별 파티클 16개 폭발 (캐릭터 위치) | |

| 0.6s | 텍스트 페이드아웃 | |

> 게임 일시정지 X — 자동 공격 계속.

### 4.3. 추억 발견 연출 (1.2초)

```
화면 중앙에 추억 픽업 → 흡수 → 0.5초 정지 + 화면 어두워짐
"아빠의 사진을 발견했어요!"
[일기장에 보관됨]  사진 미니 미리보기
↓
1.2초 후 자동 닫힘 + 게임 재개
```

> 추억 발견은 4번뿐인 1회성이라 일시정지 + 강조 OK.

### 4.4. 적 처치 시각 (CLAUDE.md §2 톤)
