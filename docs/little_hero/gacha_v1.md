- 결과 — 이전 소환과 동일 등급 분포 (1번이라도 Rare+ 안 나오면 마지막 1회 강제 Rare+)

## 3. 장비 슬롯 업그레이드 = 스타포스 시스템 (신규)

### 3.1 핵심 — 슬롯 강화 (장비 강화 X)

**메이플 키우기 패턴 그대로**:
- 장비 자체가 아닌 **슬롯** 강화
- 장비 교체해도 슬롯 강화 단계 유지 ✅
- 슬롯별 독립 강화 (모자 ⭐15 / 무기 ⭐20 등 가능)

### 3.2 단계 — 0~25 (사용자 결정 7)

**안전 강화** — 하강 X, 파괴 X.

| 단계 | 효과 | 비용 (스타포스 조각) | 성공 확률 |
|---|---|---|---|
| ⭐0 → ⭐1 | base +5% | 100 | 100% |
| ⭐5 → ⭐6 | base +30% | 500 | 100% |
| ⭐10 → ⭐11 | base +60% | 2,000 | 95% |
| ⭐15 → ⭐16 | base +100% | 8,000 | 75% |
| ⭐20 → ⭐21 | base +160% | 30,000 | 50% |
| ⭐24 → **⭐25** | base **+200%** | 100,000 | 30% |

**실패 시**: 비용 차감 + 단계 그대로 (재도전 가능). **하강·파괴 X** (캐주얼 친화).

### 3.3 효과 분리 — 장비 base / 슬롯 % 강화 (사용자 결정 6)

```
장비 인스턴스: base 옵션 (예: 모자 = +50 공격력)
       ↓
슬롯 ⭐10 강화: base × (1 + 0.6) = +80 공격력
       ↓
주옵션 3줄: + 추가 비율
       ↓
부옵션 3줄: + 추가 절대값
       ↓
스탯 코어 + 신화 효과
```

**결과**: 슬롯 ⭐ 단계 ↑ 시 base 효과 % 강화. 장비 교체해도 ⭐ 그대로 유지 → 사용자가 더 높은 등급 장비 획득해도 강화 재투자 없이 즉시 효과.

### 3.4 스타포스 조각 — 가챠 부수 획득

가챠 굴림 시 등급별 조각 획득:

| 굴림 등급 | 조각 |
|---|---|
| Common | +1 |
| Magic | +2 |
| Rare | +5 |
| Epic | +15 |
| Legendary (출시 후) | +50 |
| **Mythic** | **+200** |

**추가 출처**:
- 일일 로그인 보너스 +5 조각/일
- 챕터 첫 클리어 보상 +N×3 조각 (N = 챕터 번호)
- 일일 보스 처치 +20 조각
- 주간 보스 처치 +100 조각

### 3.5 ⭐25 풀빌드 비용 시뮬

- 단판 1슬롯 ⭐0 → ⭐25 누적 비용 ≈ **약 1,200,000 조각**
- 12 슬롯 풀빌드 ≈ 14,400,000 조각
- 비과금 평균 (일일 100 조각) → 144,000 일 (장기)
- 캐시 (별빛 ⋆ 가챠) 활용 시 단축 가능
