## 1. 핵심 결정

- **4번째 화폐**: **별빛 ⋆** — 실금 + 일일 보너스로 획득. 영구.
- **과금 유도 채널**: **장비 성능 업그레이드만**.
  - 마법 결정 ◇ 직구매 (강화 가속)
  - 강화 100% 보장권 (RNG 보호)
  - 옵션 라인 영구 잠금 (좋은 affix 보존)
  - 신화 마일리지 가속
- **레벨업 가속 옵션 ❌** — XP 부스트·레벨 점프는 미도입. "장비가 빛나는 게임" 정체성.
- **비과금으로 100% 클리어 가능**: 별빛은 "시간 단축" 만. 콘텐츠 락 X, 능력치 락 X.
- **4+ 등급 적합 원칙**:
  - ❌ 가챠·확률형 아이템 (한국 법규 + 4+ 적합 X)
  - ❌ FOMO 타이머·한정 아이템
  - ❌ 광고 시청 강제
  - ❌ 페이투윈 독점 능력치
  - ✅ 명시적 가격·즉시 적용
  - ✅ 코스메틱·편의·시간 단축

## 3. 별빛 출처

### 3.1. 무료 별빛 (비과금 베이스)

| 출처 | 별빛 | 빈도 | 누적 (예시) |
|---|---|---|---|
| 일일 로그인 | 5 ⋆ | 매일 | 30일 = 150 ⋆ |
| 챕터 첫 클리어 | N × 2 ⋆ | 1회/챕터 | 35 챕터 = 1,260 ⋆ |
| 추억 발견 | 10 ⋆ | 1회/추억 | 4 종 = 40 ⋆ |
| 도감 100% (챕터별) | 50 ⋆ | 1회/챕터 | 35 챕터 = 1,750 ⋆ (매우 긴 그라인드) |
| 일일 보스 첫 클리어 | 5 ⋆ | 매일 | 30일 = 150 ⋆ |
| 주간 보스 첫 클리어 | 20 ⋆ | 주 1회 | 4주 = 80 ⋆ |
| 시즌 패스 무료 선 | 100 ⋆ | 시즌 (3개월) | — |

**비과금 누적 (35 챕터 첫 클리어 + 6개월 endgame)**:
- 35 챕터 첫 클리어: ~3,200 ⋆
- 일일 로그인 6개월: ~900 ⋆

- 시즌 패스 무료: 200 ⋆ (2 시즌)

## 4. 별빛 사용처 — 장비 강화 중심

### 4.1. 화폐 변환 (주 채널)

| 항목 | 별빛 비용 | 효과 |
|---|---|---|
| 마법 결정 ◇ 1개 | **5 ⋆** | 강화 +16+ 가속 |
| 마법 결정 ◇ 5개 | **22 ⋆** | 약 12% 할인 |
| 마법 결정 ◇ 10개 | **40 ⋆** | 약 20% 할인 |
| 무지개 구슬 ✦ 10개 | 20 ⋆ | 메타·장신구 가속 |
| 별가루 ★ 1,000개 | 10 ⋆ | (인플레 흡수, 거의 의미 없음 — 변환 모루 권장) |

### 4.2. 강화 RNG 보호

| 항목 | 별빛 비용 | 효과 |
|---|---|---|
| 강화 100% 보장권 | **30 ⋆** | 1회 강화 무조건 성공 (천장 게이지 영향 없음) |
| 천장 게이지 +5 | 15 ⋆ | 천장 도달 가속 |
| 강화 자원 절반 | 20 ⋆ | 1회 강화 비용 별가루·마법 결정 50% |

### 4.3. 옵션 라인 가속

| 항목 | 별빛 비용 | 효과 |
|---|---|---|
| 주옵션 라인 영구 잠금 | **50 ⋆** | 1줄. 다음 모든 리롤에도 잠김 (별가루 1줄 잠금은 1회성) |
| 부옵션 라인 영구 잠금 | 30 ⋆ | 1줄 |
| 부옵션 등급 +1 보장 | **40 ⋆** | 다음 등급 향상 시 보장 (Common→Uncommon 등) |
| 주옵션 1회 무료 리롤 | 15 ⋆ | (별가루 절약) |

### 4.4. 신화 옵션 가속

| 항목 | 별빛 비용 | 효과 |
|---|---|---|
| 마일리지 +20 | **100 ⋆** | 신화 옵션 발현 마일리지 가속 |
| 신화 발현 보장 (마일리지 50+) | 300 ⋆ | 다음 강화 시 신화 발현 보장 |

> 신화 가속은 비싸게 — 메가 잭팟의 자연 발현이 메인.

### 4.5. 편의 (후속, 검토)

| 항목 | 별빛 비용 | 비고 |
|---|---|---|
| 인벤토리 슬롯 +10 | 80 ⋆ | (인벤토리 시스템 도입 시) |
| 캐릭터 슬롯 (4번째) | 200 ⋆ | (후속 캐릭터 추가 시) |
| 코스메틱 (펫 외형) | 50~150 ⋆ | (외형 X 능력치) |
| 아빠의 일기 페이지 | 30 ⋆ | 추억 추가 모음 (스토리 확장) |

## 5. 비과금 vs 과금 시뮬

### 5.1. 케이스 A — 비과금 라이트 유저

- 6개월 플레이, 일일 로그인만, 챕터 1~25 클리어
- 별빛 누적: 1,400 ⋆
- 사용: 마법 결정 ◇ 280 직구매 (적자 해결) + 강화 보호권 5회 + 잔여 ~600 ⋆
- 결과: 메인 콘텐츠 클리어 + 일부 슬롯 +20

### 5.2. 케이스 B — 비과금 헤비 유저

- 1년 플레이, 일일·주간 보스 매번, 챕터 1~35 + endgame
- 별빛 누적: 8,000 ⋆
- 사용: 마법 결정 ×500 (가속 풀 +20 + 일부 +25) + 잠금 영구 30회 + 신화 가속
- 결과: 풀 +20 + 핵심 슬롯 +25 + 신화 4~6종

### 5.3. 케이스 C — 과금 정상 유저 (월 5,000원)

- 6개월 플레이, 5,500원 패키지 ×6 = 33,000원 = 3,300 ⋆ 추가
- 누적: 1,400 + 3,300 = **4,700 ⋆**
- 사용: 마법 결정 ×600 + 강화 보호 풀 + 영구 잠금 풀 + 신화 가속 일부
- 결과: 풀 +25 + 신화 8종 (6 개월 만에 헤비 비과금 1년치 도달)

### 5.4. 케이스 D — 과금 헤비 유저 (월 30,000원)

- 6개월, 33,000원 패키지 ×6 = 198,000원 = 23,400 ⋆ 추가
- 별빛 사용: 마법 결정 풀 + 강화·잠금·신화 모두 가속
- 결과: 6개월 안에 풀 +25 + 모든 슬롯 신화 발현

> 케이스 C·D 가 모두 도달 가능한 풀빌드 = **모든 클래스 12 슬롯 +25 + 신화**.
> 비과금도 **결국 도달 가능** (12개월~24개월). "시간 vs 돈" 트레이드오프, 능력치 격차 X.

## 6. 가이드 원칙

### 6.1. 4+ 등급 + 키즈 톤 적합

- ❌ 가챠 (확률형) — 본 게임의 affix 굴림은 "구매 후 굴림"이라 가챠 X
- ❌ FOMO 한정 (시간 압박) — 시즌 패스만 부드러운 시즌제
- ❌ 광고 시청 강제 — 후속 도입 시에도 옵션, 보상 동일하게
- ✅ 명시적 가격 + 즉시 적용
- ✅ 환불 정책 (App Store 정책 준수)

### 6.2. 디자인 의도 정합

- 과금 = "내 장비가 더 빛나기 위한 가속"
- 비과금 = 같은 빌드 도달 가능, 단 시간 더 소요
- 능력치 락·콘텐츠 락 ❌ — 별빛은 모든 콘텐츠를 비과금으로 클리어 가능한 전제 위에서만

### 6.3. UI 표시 원칙

- 별빛 가격은 **항상 명시** (별빛 X 가루 단위 X)
- 특가·세일 X (가격 변동성으로 구매 압박 X)
- "구매" 버튼은 항상 명확 (실금 진입 명시)

### 7.2. StarlightShopService

```csharp
public class StarlightShopService
{
    public bool TryBuy(StarlightItem item)
    {
        if (SaveData.starlight < item.cost) return false;
        SaveData.starlight -= item.cost;
        ApplyEffect(item);
        SaveSystem.Save();
        return true;
    }
}

public enum StarlightItem
{
    MagicCrystal_1, MagicCrystal_5, MagicCrystal_10,
    EnhanceGuarantee, PityGaugePlus5, EnhanceCostHalf,
    PermanentLockMain, PermanentLockSub, SubGradeBoost,
    MythicMileagePlus20, MythicGuarantee,
}
```

### 7.3. CurrencyService 확장

```csharp
public static class CurrencyService
{
    // ... 기존

    public static void GrantStarlight(int amount)
    {
        SaveData.starlight += amount;
        SaveSystem.Save();
        GameEvents.RaiseStarlightChanged(SaveData.starlight);
    }

    public static int CalcChapterStarlightReward(int chapterN)
        => chapterN * 2;  // 35 챕터 첫 클리어 = 1,260 ⋆

    public static int CalcDailyLoginStarlight() => 5;
    public static int CalcMemoryStarlight() => 10;
}
```
