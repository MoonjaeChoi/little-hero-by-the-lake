# §1. 전체 흐름 — 게임 정체성

## 1.1 핵심 정체성

```
호숫가 작은 영웅 (4+ 등급) = 비폭력 키즈 톤 + 자동 슈팅 ARPG
   ↓
잭팟 ARPG 깊이 (5층 아이템 + 강화 천장 + 신화) — Direction v2
   ↓
35 챕터 + 다락방 + 아빠의 추억 (스토리 코어)
```

**결정 이력**:
- 2026-04-29 초기: 단순 Auto-Shooter (Phase 1·2)
- 2026-04-30 Direction v2: 4대 방향성 도입 (모바일 / XP / 자부심 / 챕터 동조)
- 2026-04-30~05-01: 잭팟 ARPG 11 시스템 적용 (5층 아키텍처·강화·신화)

**현재 상태**: ✅ Phase A~F 51 태스크 100% 완료. iOS 빌드 직전.

## 1.2 ❓ 토론 포인트 — 정체성 균형

# §2. 4 화폐 — 분리 vs 단순화

## 2.1 4 화폐 카탈로그

| 화폐 | 영구성 | 출처 | 사용 |
|---|---|---|---|
| 별가루 ★ | 런 내 | 적 처치 / 상점 보상 | 상점·새로고침 / 리롤 / 강화 (~+15) |
| 무지개 구슬 ✦ | 영구 | 챕터 첫 클리어 / 추억 | 마음 단련 / 장신구 상점 / 변환 |
| 마법 결정 ◇ | 영구 (강화 전용) | 보스 / 변환 모루 | +16~+25 강화 |
| 별빛 ⋆ | 영구·캐시 | 일일 로그인·챕터·도감·IAP | 강화 가속 / 마법 결정 직구매 |

## 2.2 결정 이력

- ✅ 4 화폐 분리 (각 영역 명확) — economy_v1 §1
- ✅ 변환 모루 (1000★:1◇ / 5✦:1◇) — 적자 자체 해결
- 시뮬 결과: 35 챕터 풀빌드 시 마법 결정 -151 ◇ → 변환 후 +157 ◇ ✅

## 2.3 ❓ 토론 포인트

| Q | 토론 |
|---|---|
| Q2.1 | 사용자 인지 부하 — 4 화폐 아이콘·이름 모두 기억 필요. 3 화폐로 단순화 가능? |
| Q2.2 | 마법 결정 분리의 가치 — 단순히 +16~+25 강화 자원이라면 별가루 통합 가능? |
| Q2.3 | 별빛 ⋆ 캐시 vs 무료 출처 비율 — 현재 무료 출처 풍부. 캐시 가치 약화? |

```
챕터 진행 (콘텐츠) — 35 챕터 첫 클리어 후 hardcore 36~50
   ↑                                            ↑
   └─────────── 직교 (서로 무관) ─────────────────┘
                    ↓
시즌 진행 (운영) — 4단계 시즌 패스 + 코스메틱 보상
```

# §4. 자부심 코어

## 4.1 자부심 = 갈수록 강해지는 캐릭터

**Direction v2 §3** — "캐릭터·장비 자부심" 핵심 결정:
- 사망 시 XP 후퇴 없음
- 강화 +25 + 신화 발현 = 영구 인벤토리 자산
- 이전 챕터로 돌아갈 때 **이전보다 훨씬 강해진** 자신을 느낌

## 4.2 결정 이력

- ✅ 사망 페널티 미도입 (XP·인벤토리 보존)
- ✅ 강화 +25 영구 + 신화 영구 부착
- ✅ 챕터 첫 클리어 후 반복 시 보상 ↓ (BossRepeat 30%) — 자부심 보상 분리

## 4.3 ❓ 토론 포인트

| Q | 토론 |
|---|---|
| Q4.1 | 자부심 강조 = 도전 부재 — 사용자가 "쉬워서 지루" 느낄 가능성 (특히 캐주얼 X 라이트 ARPG 사용자) |
| Q4.2 | 사망 시 후퇴 없음 — 무한 도전 가능 = 시간 압박 vs 진지함 균형 |
| Q4.3 | 신화 발현 후 다음 자부심 축? L100 + 신화 풀 + +25 강화 모두 달성 후 |
