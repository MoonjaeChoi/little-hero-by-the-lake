## 1. `stats_v1.md` — 능력치 시스템

### 핵심 결정
- **4 코어 스탯**: 힘 / 빠름 / 슬기 / 마음 (Diablo 4 모델)
- **3 데미지 버킷**: 합산 (Additive) / 최종 (Multiplicative) / 크리 (Critical) — 분리·곱셈
- **메이플 키우기 부위별 채널**: 부위마다 고유 옵션 (모자=공격력 / 가방=드랍률 등)
- **스킬 시스템 미채용** (탭 1회로 단순 자동 슈팅)

### 의존
- 영향 → equipment_v1 (장비 효과 입력) / affix_pool_v1 (옵션 채널) / character_progression_v1 (XP→스탯)

### 미해결 토론 포인트
- [ ] 4 코어 100점당 부수 효과 정확한 수치 (현재 §3.2 placeholder)
- [ ] 크리 확률·피해의 디자인 상한 (확률 75% 이상 시 ARPG 가독성 ↓)
- [ ] 방어 관통 vs 적 방어력 곡선 정합 (chapter_curve §3 검증 필요)

## 2. `equipment_v1.md` — 장비 시스템 (5층 아키텍처)

### 핵심 결정
- **12슬롯**: 주 7 (모자/상의/하의/망토/장갑/무기/신발) + 장신구 5 (귀걸이/안경/목걸이/반지/펫)
- **5층 아키텍처**: 1=베이스 / 2=강화(+0~+25) / 3=리롤 / 4=주옵션 3줄 / 5=신화 옵션
- **세트 효과 폐기** (2026-04-30) — 능력치 합산 + 외형/이펙트 다양성으로 차별화
- **3-티어 장신구** — 메이플 키우기 영감 (Common→Uncommon→Rare→Epic 챕터별 해방)

### 의존
- 영향 ← stats_v1 (스탯 입력) → affix_pool_v1 (옵션 풀) / item_drop_v1 (인스턴스 생성)

### 미해결 토론 포인트
- [ ] 신화 발현 조건 — 마일리지 50 + 추억 4종 OR 가능성? (현재 AND)
- [ ] 장신구 5종 추가 시점 (챕터 6~10 첫 클리어) 의 UX 통지 방식
- [ ] 강화 +25 도달 후 다음 진행 축 (=별빛 가속 외 신규 시스템 필요?)

## 3. `affix_pool_v1.md` — L4 주옵션 카탈로그

### 핵심 결정
- **22 unique 주옵션** (문서 §7.4 의 "23종" 은 실제 unique 합산 22 — 오기)
- **슬롯별 풀 가중치** 6:3:1 (1차/2차/3차 분류)
- **등급별 정확한 수치 표** §2 — Common~Legendary 4 등급
- **잠금 + 리롤** §4.2 — 잠금당 비용 ×1.5

### 의존
- 영향 ← stats_v1 (StatTarget) ← equipment_v1 (슬롯 정의) → item_drop_v1 (굴림)

### 미해결 토론 포인트
- [ ] Affix 22 vs 23 — 추가 1종 도입 시 우선순위 (예: 흡혈, 회피)
- [ ] 슬롯 풀 가중치 6:3:1 의 균형 — 1차 옵션이 너무 자주 등장하지 않는지
- [ ] 부옵션 (글로벌 12종) 의 채널 다양화 (현재 12종 → 16~20종 확장 가능?)

## 4. `item_drop_v1.md` — 드랍·이중 옵션

## 5. `character_progression_v1.md` — XP·레벨

### 핵심 결정
- **L100 캡 + piecewise 곡선** — L1~50 빠름 (1.15^L) / L51~100 둔화 (1.05^x)
- **35 챕터 권장 레벨 매트릭스** (CH N+10 정도)

- **L51+ 둔화 보상 효과** — HP+5·공격력+0·부수 0 (스탯 공격력 정체)

### 의존

### 미해결 토론 포인트

## 8. `economy_v1.md` — 4 화폐

### 핵심 결정
- **4 화폐 분리** — 별가루 ★ (런 내) / 무지개 구슬 ✦ (영구) / 마법 결정 ◇ (강화 전용) / 별빛 ⋆ (캐시)
- **변환 모루** — 별가루 1000 ★ : 1 ◇ / 무지개 구슬 5 ✦ : 1 ◇
- **풀빌드 정합 시뮬** — 마법 결정 적자 (-151 ◇) 변환 모루로 자체 해결 (+157 ◇)
- **chapter 보상 매트릭스** — CH N 첫 클리어 = ✦ N×1 + ◇ 1+N/3 + ⋆ N×2

### 의존
- 영향 ← chapter_curve_v1 (보상 곡선) ← equipment_v1 (강화 비용) → monetization_v1

### 미해결 토론 포인트

- [ ] 변환 모루 비율 1000:1 / 5:1 의 균형 — 무지개 구슬 변환이 유리?
- [ ] 챕터 N 보상 공식의 게임 후반 (CH 30~35) 인플레이션
