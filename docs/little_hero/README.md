# Little Hero — 잭팟 ARPG 적용 인덱스

> 잭팟 ARPG 설계서(`../`)와 Little Hero by the Lake(Unity 프로젝트, `../../LittleHero/`)를 **하나의 게임으로 통합**하기 위한 적용 문서들.
>
> Jackpot ARPG의 5층 아이템 아키텍처·강화 천장·신화 옵션·시즌제 메커니즘을, Little Hero의 비폭력 키즈 톤(별·하트·꽃잎, CLAUDE.md §2)과 챕터 동화책 스토리(빨간모자/잭과 콩나무/앨리스)에 호환되게 재해석한다.

---

## 톤·세계관 매핑 원칙

잭팟 ARPG 설계는 액션·코어 톤을 가정한다. Little Hero에 적용할 때는 **시각·언어·실패 표현이 모두 친근**해야 한다 (CLAUDE.md §2 절대 원칙).

| 잭팟 ARPG 원본 | Little Hero 적용 |
|---|---|
| 강화 실패 시 자원 소모 | "별가루가 흩어졌어요" — 별/하트 파티클 흐려짐 |
| 천장 도달 시 100% 보장 | "아빠가 도와주실 거예요" — 아빠의 손글씨가 잠깐 비침 |
| 신화 옵션 발현 | "아빠의 마법이 깨어났어요" — 무지개 빛 + 추억 메시지 |
| 등급 색상 (gray/green/blue/purple/gold) | 채도 60~70% 파스텔로 다운 |
| "메가 잭팟"·"DPS"·"버스트" 같은 코어 용어 | 어린이 어휘로 — "큰 별", "공격력", "한 번에" |
| 시즌제 코스메틱 | 챕터 클리어로 얻는 칭호·리본·스티커 |

## 기존 Little Hero 시스템과의 결합

| Jackpot ARPG | 기존 Little Hero | 결합 방안 |
|---|---|---|
| 5층 아이템 아키텍처 | `EquipmentData` 16종 (현행, 7슬롯) | 마스터 = `EquipmentTemplate`, 인스턴스 = `EquipmentInstance` 분리. ✦ 슬롯 12개로 확장(주 7 + 장신구 5), 가방 슬롯 폐기 |
| 강화 +0~+25 + 천장 | 없음 (현재 장비는 정적) | 신규 강화 시스템 도입, 별가루(`★`)가 강화 자원 |
| 옵션 라인 3개 + 리롤 | 없음 | 신규. 무지개 구슬(`✦`)으로 리롤 |
| 세트 효과 | `EquipmentData.setId` (정의만) | ✦ **전면 폐기 (2026-04-30)** — 순수 능력치 합산 + 외형/이펙트 다양성으로 차별화 |
| ✦ 장신구 3-티어 시스템 | 없음 | **메이플 키우기 영감** — 챕터 6~10 슬롯 해방 + Common, 16~20 향상(Uncommon~Rare), 26~30 정점(Rare~Epic). 슬롯 순서는 **귀걸이→안경→목걸이→반지→펫**로 모든 티어에서 동일 |
| 신화 옵션 | 없음 | **아빠의 추억(MemoryData) 시스템과 결합** — 추억 4종 모으면 풀 언락 |
| 캐릭터 진행 (XP/Level) | `CharacterData` 3종 + 베이스 스탯 | XP 적립 시스템 신규 추가 (Part 1b) |
| 챕터 진행 + 동조 성장 | 챕터 1/2/3 + 보스 SO 이미 있음 | 그대로 활용 + 적 강화 곡선 + 보상 매트릭스 추가 + ✦ 챕터 클리어 시 슬롯 해방 보상 |
| 시즌제 듀얼 실현 | 없음 | MVP에서는 **제외** — 키즈 게임에 시즌 압박은 부적절 |
| 모바일 전용 | iOS 1차 (CLAUDE.md §1) | 정합 |

> **시즌제만 MVP에서 명시적으로 제외**한다. 키즈 ARPG에서 시즌 FOMO는 자부심 코어와 충돌하기 때문. 출시 후 서비스 안정 시점에 재검토.

## 메모 — 이 통합의 의미

지금까지 Little Hero 프로젝트는 Phase 1·2·3 작업으로 16종 장비, 3챕터, 캐릭터·추억·도감·메타 업그레이드를 갖췄다. 그러나 그 시스템들은 **상대적으로 단순한 진행 모델**이었고, 잭팟 ARPG 설계서가 도입되며 **장기 동기·자부심·빌드 다양성**의 깊이가 추가된다.

핵심은 "Little Hero의 따뜻한 정서 + 잭팟 ARPG의 깊이". 둘 중 하나라도 무너지면 게임이 정체성을 잃는다.
