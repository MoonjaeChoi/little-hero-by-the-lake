## 1. 핵심 결정

- **3 화폐 분리**:
  - **별가루 ★** (런 내, 휘발) — 적 처치, 챕터 보상. 챕터 단위로 0 리셋.
  - **별 조각 ✦** (영구) — 챕터 첫 클리어, 일부 반복.
  - **별 모래 ◆** (영구, 신규) — 보스 처치 시. **+16 이상 강화 전용**.
- **이름 결정**: 강화석 = **"별 모래"** (equipment_v1 §7 미해결 → 본 문서가 결정). UI 심볼 `◆`.
- **소비 원칙**:
  - 별가루 → 강화 +0~+25 + 주/부 리롤 + 인게임 상점 (현 ShopController)
  - 별 조각 → 메타 업그레이드 + 장신구 직구매 + 부옵션 등급 향상권
  - 별 모래 → 강화 +16 이상에만
- **수입 곡선**: chapter_curve_v1 §2 의 `1.08^(N-1)` 곱셈을 그대로 채용 (별가루·별 조각 동일).
- **장기 균형**: 35 챕터 첫 클리어로 **메인 슬롯 풀 +20 + 일부 +25** 빌드 가능. 풀 +25 12 슬롯은 반복 파밍 필요 (장기 동기).

### 7.4. 정합 검증

- **35 챕터 첫 클리어 263 ◆** vs **12 슬롯 +20 합계 396 ◆** → 모자람. **반복 파밍 필요**.
- 12 슬롯 풀 +20 도달까지: 첫 클리어 263 + 반복 보스 ≈ 4 챕터 ×반복 → 약 **150 ◆ 추가** 필요 = 챕터 25~30 보스 5~8회 반복.

→ "30 챕터 클리어 후 일부 슬롯 +20 + 챕터 30 보스 5번 반복으로 풀 +20 도달" 경로가 현실적.

> 풀 +25 12 슬롯은 **MVP 범위 밖** — 출시 후 시즌 콘텐츠로 별 모래 추가 수익원 도입 필요.

## 8. 통합 시뮬: 35 챕터 풀빌드까지

| 항목 | 별가루 ★ | 별 조각 ✦ | 별 모래 ◆ |

| **잔여** | **+257,378** | **+338** | **-125** ⚠️ |

### 8.1. 별 모래 적자 해결 옵션

1. **반복 파밍** (현 설계) — 챕터 25~30 보스 6~10회 반복 → +150 ◆.
2. **추억 보상 강화** — 추억 4종 × 2 ◆ → 4종 × 5 ◆로 상향 시 적자 -125 → -113 (거의 동일).
3. **미니보스 ◆ 확률 상향** — 챕터 11+ 30% → 50%, 챕터 21+ 50% → 70% → 추가 +50 ◆.
4. **챕터 클리어 보너스** — 챕터 N × 0.3 ◆ 신설 → 35 챕터 누적 +183 ◆ → 적자 해소 + 잉여.

> 권장: **3번 + 4번** 결합. 1번(반복)은 백업 + 풀 +25 빌드로 가는 동기 보존.

### 8.2. 권장 곡선 조정 (사용자 결정 후 적용)

| 항목 | 현재 | 권장 조정 |
|---|---|---|
| 미니보스 ◆ 확률 (CH 11+) | 30% | **50%** |
| 미니보스 ◆ 확률 (CH 21+) | 30% | **70%** |
| 챕터 클리어 ◆ 보너스 | 없음 | **챕터 N × 0.3 ◆** (신규) |
| 추억 ◆ 보상 | 2 ◆ × 4종 | 5 ◆ × 4종 |

조정 후 35 챕터 첫 클리어 별 모래 ≈ **520 ◆** → 풀 +20 (396 ◆) + 핵심 5 슬롯 +21~+22 가능.

```csharp
    }

    public static int CalcChapterStarFragmentReward(int chapterN, bool isFirst)
    {
        int baseReward = Mathf.RoundToInt(5f * Mathf.Pow(1.10f, chapterN - 1));
        return isFirst ? baseReward : Mathf.RoundToInt(baseReward * 0.25f);
    }

    public static int CalcChapterStarStoneReward(int chapterN, bool isFirst)
    {
        int baseReward = Mathf.RoundToInt(1f + chapterN / 3f);
        return isFirst ? baseReward : Mathf.RoundToInt(baseReward * 0.4f);
    }
}
```
