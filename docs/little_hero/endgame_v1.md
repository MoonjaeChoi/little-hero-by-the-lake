# Little Hero — Endgame 콘텐츠 v1

> [← Little Hero 인덱스](./README.md) · [캐릭터 진행 v1](./character_progression_v1.md) · [챕터 곡선 v1](./chapter_curve_v1.md) · [경제 v1](./economy_v1.md) · [수익화 v1](./monetization_v1.md)
>
> 35 챕터 첫 클리어 + L50 도달 후의 **L51~L100 endgame 콘텐츠**. 보스 강화·반복·일일·주간·무한 + 보상 곡선.

---

## 1. 핵심 결정

- **잠금 해제 조건**: 챕터 35 첫 클리어 + L50 도달.
- **L51~L100 진행 페이스**: 6~12개월 (장기 그라인드), 일일/주간 콘텐츠가 안정 수익원.
- **5 endgame 모드**:
  1. **챕터 반복** (existing) — 동일 챕터 재플레이, 첫 클리어의 25%~30% 보상
  2. **고난도 챕터 (CH 36~50)** — 챕터 1~15 어둠 모드 + 적 ×2 + 보상 ×3
  3. **일일 보스** — 매일 1회 도전, 안정 수익
  4. **주간 보스** — 주 1회 도전, 신화 옵션 발현 보장
  5. **무한 모드** (끝없는 다락방) — 깊이 → 보상 비례
- **보상 강화**: 마법 결정 ◇ + 별빛 ⋆ (캐시 화폐, monetization_v1) + 한정 코스메틱
- **레벨업이 둔화되는 것은 의도** — 캐릭터는 거의 다 컸고, 이제 **장비 강화**가 주된 성장.

## 2. 잠금 해제 흐름

```
챕터 1 클리어 → ... → 챕터 35 클리어 (메인 스토리 완료)
    ↓
L50 도달 (또는 35 클리어 시점에 자동)
    ↓
"마지막 페이지" 모달 등장
    "다락방의 지도 너머로 더 많은 모험이 펼쳐져요!"
    ↓
다락방 메뉴에 4 endgame 모드 추가 (고난도 / 일일 / 주간 / 무한)
챕터 반복은 챕터 클리어 직후부터 가능 (잠금 해제 X)
```

## 3. 고난도 챕터 (CH 36~50)

### 3.1. 컨셉

기존 챕터 1~15를 "어둠 모드"로 다시 도전. 적·보스 강화 + 보상 곡선 ×3.

### 3.2. 매핑

| 고난도 # | 원본 챕터 | 컨셉 |
|---|---|---|
| CH 36 | 1 호숫가 작은 마을 | "그림자 마을" |
| CH 37 | 2 잊혀진 학교 | "꿈속의 교실" |
| CH 38 | 3 깊은 다락방 | "거꾸로 다락방" |
| ... | ... | ... |
| CH 50 | 15 (자연 전환 끝) | "환영의 자연" |

> 35 클리어 후 한 묶음씩 해제 (CH 36~40 첫 그룹). 반복 가능.

### 3.3. 적 스탯 곡선

```
고난도_적_HP(N=36~50) = 챕터_원본_HP(N - 35) × 2 × 1.10^(N - 36)
                       = 원본 × 2 × 챕터 진행 곱셈

예: CH 36 (원본 CH 1) 일반 HP = 44 × 2 × 1.0 = 88
    CH 50 (원본 CH 15) 일반 HP = 167 × 2 × 1.10^14 = 167 × 2 × 3.80 = 1,269
```

### 3.4. 보상

| 항목 | 일반 챕터 (35) | 고난도 챕터 (36~50) |
|---|---|---|
| 별가루 ★ | 챕터 35 = 24,626 | × 1.5 → ~37,000 |
| 무지개 구슬 ✦ (첫) | 5 × 1.10^(N-1) = 126 | × 2 → ~252 |
| 마법 결정 ◇ (첫) | 1 + N/3 = 13 | × 2 → ~26 |
| 별빛 ⋆ (첫) | N × 2 = 70 | × 1.5 → ~105 |
| 보스 affix 등급 | Rare~Epic | Epic~Legendary 가중 |

### 3.5. 반복 보상

- 첫 클리어 100% → 반복 50% (일반 챕터는 25%, 고난도는 50%로 더 후함)
- 매일 1회 한정 보너스 (×2 보상) — daily reward 인센티브

## 4. 일일 보스 ("아빠의 일기 도전")

### 4.1. 컨셉

매일 1회 도전. 보스는 7종 회전 (요일별 다른 보스), 강력하지만 단일 웨이브.

### 4.2. 보스 매트릭스 (요일별)

| 요일 | 보스 | 모티브 | 약점 |
|---|---|---|---|
| 월 | 큰 늑대 추억 | CH 7 어둠 | 빠름 (회피) |
| 화 | 거인의 그림자 | CH 14 거인 | 슬기 (사거리) |
| 수 | 카드 여왕의 분노 | CH 32 환상 | 마음 (HP) |
| 목 | 별구름 폭풍 | CH 1 미니 강화 | 힘 (공격력) |
| 금 | 안개 곰 거대화 | CH 6 보스 강화 | 크리티컬 |
| 토 | 모래 회오리 정점 | CH 10 보스 강화 | 공격 속도 |
| 일 | 모든 보스 랜덤 | 종합 도전 | 균형 빌드 |

### 4.3. 스탯 스케일

```
일일_보스_HP = 보스_베이스_HP × 1.10^(player_max_chapter_cleared - 1) × 5
일일_보스_ATK = × 5
```

> 플레이어가 도달한 최고 챕터에 따라 자동 스케일. 항상 도전감 유지.

### 4.4. 보상

| 항목 | 첫 클리어 (1일/회) | 반복 (X — 일일은 1회만) |
|---|---|---|
| 마법 결정 ◇ | **5** | — |
| 별빛 ⋆ | **5** | — |
| 무지개 구슬 ✦ | **10** | — |
| XP | 50,000 | — |

> 매일 5 ◇ × 30일 = **150 ◇/월** — 풀 +20 12 슬롯 (396 ◇) 의 약 38%/월.

## 5. 주간 보스 ("환상의 거대 친구")

### 5.1. 컨셉

주 1회 (매주 월요일 자정 리셋) 도전. **신화 옵션 발현 보장**의 메가 잭팟.

### 5.2. 보스 매트릭스 (주별 회전)

| 주 (4주 사이클) | 보스 | 컨셉 |
|---|---|---|
| 1주차 | 거대한 빛 펭귄 | 크기 거대 + 빙판 |
| 2주차 | 거대한 별 양 | 별빛 양 떼 + 본체 |
| 3주차 | 거대한 무지개 새 | 비행 + 무지개 빛 |
| 4주차 | 거대한 그림자 친구 | 어둠 + 본인 추억 |

### 5.3. 스탯 스케일

```
주간_보스_HP = 일일_보스_HP × 5 (≈ 25배 일반 보스)
주간_보스_ATK = × 3
```

### 5.4. 보상

| 항목 | 첫 클리어 (주 1회) |
|---|---|
| 마법 결정 ◇ | **30** |
| 별빛 ⋆ | **20** |
| 무지개 구슬 ✦ | **50** |
| XP | 200,000 |
| 신화 옵션 발현 보장 | **1회** (장착 장비 중 무작위) |

> 주 30 ◇ × 4주 = **120 ◇/월** — 일일 + 주간 합쳐 **270 ◇/월** = 빠른 풀 +20 가능.
> 신화 옵션 발현 보장 = **메가 자부심**. 4주 사이클 내 4회 신화 가능 (장착 12종 중 중복 가능).

## 6. 무한 모드 ("끝없는 다락방")

### 6.1. 컨셉

다락방 깊은 곳에 숨겨진 무한 계단. 매 5분마다 적 스탯 ×1.10. 죽을 때까지 진행.
누적 깊이 → 칭호·뱃지·코스메틱.

### 6.2. 진행 룰

- 5분마다 한 층 진행 (= 한 wave)
- 층마다 적 stat × 1.10 (compounding)
- 보스는 5층마다 (5/10/15/...)
- 죽으면 = 종료, 깊이 기록 저장

### 6.3. 보상 (깊이별)

| 누적 깊이 | 마법 결정 ◇ | 별빛 ⋆ | 누적 별가루 ★ |
|---|---|---|---|
| 5층 | 2 | 2 | 5,000 |
| 10층 | 5 | 5 | 15,000 |
| 20층 | 12 | 12 | 50,000 |
| 30층 | 25 | 25 | 150,000 |
| 50층 (이론적 한계) | 50 | 50 | 500,000 |

> 무한이지만 50층 이상은 거의 도달 불가 (적 stat ×1.10^50 = 117배). 칭호 "끝없는 도전자".

### 6.4. 매주 리더보드 (선택, 후속)

- 글로벌 리더보드 X (소셜 압박 회피, 키즈 톤)
- 본인 최고 깊이 vs 캐릭터별 깊이만 노출

## 7. 보스 콘텐츠 통합 보상 매트릭스

> 한 명의 플레이어가 endgame 모드를 매일·매주 활용 시 월간 수익.

| 항목 | 일일 (×30) | 주간 (×4) | 무한 (×4) | 챕터 반복 (가변) | **월 합계** |
|---|---|---|---|---|---|
| 마법 결정 ◇ | 150 | 120 | 50 | 30 | **350 ◇** |
| 별빛 ⋆ | 150 | 80 | 50 | 0 | **280 ⋆** |
| 무지개 구슬 ✦ | 300 | 200 | 0 | 50 | **550 ✦** |
| XP | 1.5M | 800k | 400k | 200k | **2.9M XP** |

### 7.1. L51~L100 도달 시간

L100 누적 XP = ~11.4M (character_progression §3.2)
월 endgame XP = ~2.9M
→ **L51~L100 도달 약 4 개월** (매일/매주 활용 가정).

> 비활용 (메인 스토리만 반복) 시 8~12 개월 — 라이트 유저.

## 8. 데이터 모델

### 8.1. 신규 SO

```csharp
[CreateAssetMenu(menuName = "LittleHero/EndgameModeData")]
public class EndgameModeData : ScriptableObject
{
    public string id;                  // "daily_boss" | "weekly_boss" | "infinite_tower" | "hardcore_chapter"
    public string displayName;
    public ModeType type;
    public int cooldownSeconds;        // 일일 = 86400, 주간 = 604800, 무한 = 0
    public RewardEntry[] firstClearRewards;
    public RewardEntry[] repeatRewards;
    public EnemyData[] bossPool;       // 일일/주간 보스
    public AnimationCurve depthScaling; // 무한 모드용
}

public enum ModeType { ChapterRepeat, HardcoreChapter, DailyBoss, WeeklyBoss, InfiniteTower }

[Serializable]
public class RewardEntry
{
    public CurrencyType currency;      // StarDust, RainbowOrb, MagicCrystal, Starlight, XP
    public int amount;
    public int chapterScaleMul = 0;    // 챕터 깊이 따라 스케일
}
```

## 11. 미해결 질문

- L51~L100 도달 4개월 가정의 검증 (시뮬·플레이테스트)
- 일일 보스 보상이 충분한가 (5 ◇/일 = 30일 150 ◇)
- 주간 보스의 "신화 보장" 이 너무 후한가 (4주 = 4 신화 발현)
- 무한 모드 50층 한계가 적절한가 (보상 cap?)
- 고난도 챕터의 보상 ×3 이 너무 후한가
- 일일 리셋 기준 (UTC vs KST? 0시 vs 6시?)
- 주간 보스 사망 시 재도전 가능 여부 (현재 가정: 가능, but 첫 클리어 보상은 1회)
- 무한 모드 중도 포기 시 보상 비율 (50%? 일부?)
- 캐릭터별 endgame 도전 패널티/보너스 (예: 조용한 친구 = 무한 모드 +10%)
