## 1. 핵심 결정

### 핵심 정체성
- **플랫폼**: ✦ **모바일 전용** (짧은 세션 + 누적 진행)
- **핵심 가치**:
  - 장기 목표 + 잭팟 추구
  - ✦ 캐릭터·장비에 대한 자부심 ("내가 굴려서 만든 것")
  - ✦ 챕터가 진행될수록 강해지는 적을 캐릭터 레벨·장비 성장으로 극복
- **장르**: 빌드 다양성 중심의 모바일 ARPG
- **영감**: 메이플스토리의 깊이 + 디아블로의 빌드 다양성 + 탕탕특공대의 진행 명확성

### 진행 모델 (✦ 신설)

게임의 골격이 되는 **챕터 진행**과 그것을 받쳐주는 **2축 성장**.

- **챕터(Chapter)**: 콘텐츠 단위. 깊이에 따라 적 HP/공격력 지수적 상승.
- **캐릭터 레벨(XP 적립)**: 결정론적 베이스 스탯 상승. 적 처치/챕터 진행 시 자동 누적.
- **장비 시스템**: 5층 아키텍처(베이스/강화/옵션/세트/신화) — 자세한 사양은 [Part 1](./part_1_equipment_identity.md)·[Part 2](./part_2_item_enhancement.md).
- 두 축이 함께 자라며 챕터 곡선을 따라잡는다. "한 번만 더 갈면 깰 수 있다" 거리감 유지.

### 타겟 유저
- **주 타겟**: 중간 코어 ARPG 유저, 시즌 메타 추구, 한 캐릭터에 수십~수백 시간 투자 의향
- **부 타겟**: 라이트 모바일 유저, 짧은 세션이지만 누적 진행 즐기는 유형
- **배제 타겟**: 1세션 30분 미만의 캐주얼 매치 게이머 (탕탕특공대 직접 경쟁 회피)

## 2. 설계 원칙

세 레퍼런스 게임의 좋은 점만 차용하되, 각각의 약점을 시스템적으로 차단하는 위치를 잡는다.

| 항목 | 차용 | 회피 |
|---|---|---|
| 메이플스토리 | 다층 RNG의 잭팟 깊이 | 신규 진입장벽 누적, 좌절 누적 |
| 디아블로 | 빌드 다양성, 시즌 회전, 데이터 주도 콘텐츠 | 한국 정서 대비 액션 위주 |
| 탕탕특공대 | 진행 명확성, 모바일 친화 UI | 낮은 깊이, 짧은 수명 |
