## 1. 모바일 전용

기존 "PC + 모바일 코어" 결정을 **모바일 전용**으로 좁힌다.

**근거**:
- 디바이스 한 종류만 책임지면 UI/입력 모델/세션 길이 가정이 단일해져 디자인·QA 비용이 크게 줄어든다.
- 모바일에 최적화된 짧은 세션 + 누적 진행 모델이 잭팟 도파민과 잘 맞는다.

**영향**:
- **Part 0**: 플랫폼 표기 갱신 (PC + 모바일 코어 → 모바일 전용)
- **Part 5**: PC 3단계 정보 밀도 섹션 제거. 모바일 카드 중심으로 단일화. PC 호버/그리드 토론 폐기.
- **Part 7**: 클라이언트 스택에서 `Next.js (웹)` 제거. 모노레포에서 `apps/web`, `packages/ui-web` 제거. React Native(Expo) 단일.
- **Part 8**: MVP에 "PC + 모바일" 동시 검증 항목 제거 → 모바일만.

## 2. 경험치 적립 → 캐릭터 능력치 상승 시스템

장비 시스템과 **별개의 축**으로 캐릭터 레벨이 존재한다. 갈면 무조건 오르는 결정론적 기반.

**핵심 사양 (초안)**:
- 캐릭터에는 `level`, `xp`, `next_level_xp` 필드.
- 적 처치/챕터 진행 시 XP 적립.
- 레벨 업 시 베이스 스탯(HP/공격력/등) 자동 상승.
- 장비 보너스는 캐릭터 베이스 위에 가산 (Effect 리졸버에서 동일 ADD/MUL/OVERRIDE 파이프라인 사용).
- 베이스 스탯과 장비 보너스의 비중은 **캐릭터 50% : 장비 50% 정도**가 자부심을 유지하면서 빌드 다양성도 살리는 시작점.

**영향**:
- **Part 1**: "결정론적 강화 + 잭팟 옵션 + 시즌 신화의 3중 구조"에 **0층(캐릭터 레벨)이 추가**되어 4중 구조가 된다. 5층 아이템 아키텍처(Part 2) 아래에 캐릭터 레벨 축이 따로 존재.
- **Part 4**: Effect 리졸버 입력에 캐릭터 레벨 베이스 스탯이 포함. `Effect.target` 도메인이 캐릭터 스탯도 가리킬 수 있어야 함.
- **Part 7**: `audit_log`/`PlayerService`에 XP 변동 기록.
- **신규 파트 권장**: `part_1b_character_progression.md` — XP 곡선·레벨 캡·스탯 상승 공식.

## 3. 내 캐릭터·장비에 대한 자부심

게임의 정서적 코어는 **"이건 내가 굴려서 만든 것"** 의 자부심이다.

**근거**:
- 잭팟의 도파민은 짧지만, 자부심은 긴 잔류 동기.
- 코스메틱 캐시샵·신화 옵션 귀속 등 기존 결정들과 정합적.

**디자인 원칙**:
- **귀속**: 캐릭터 레벨, 신화 옵션이 박힌 최종 아이템, 시즌 한정 진행도는 모두 귀속(`bound`).
- **노출**: 캐릭터 외형/칭호/펫/마운트가 다른 플레이어에게 보이는 채널 필수 (자랑 없이는 자부심도 약화).
- **회수 가치**: 분해/매각으로 적당히 환금되더라도, "굴려서 만든 결과물"은 절대 자동 폐기되지 않게 보호 옵션 제공.
- **이력 가시화**: 아이템 카드에 "총 강화 시도 N회 / 천장 N회 / 발현된 신화 X" 같은 **개인 굴림 히스토리**를 노출하면 자부심이 데이터로 시각화된다 (신규 사양).

**영향**:
- **Part 3**: 귀속/거래 정책의 "신화 박힌 최종 아이템 = 귀속" 강조 (이미 명시).
- **Part 5**: 카드 5단 위계의 1단(정체성) 또는 신화 영역에 굴림 히스토리 줄 추가 검토.
- **Part 6**: 시즌 보상의 "코스메틱·명예 영역만" 원칙 강화 (이미 명시) — 자부심을 위한 경로.

## 4. 챕터 진행 + 동조 성장 (몬스터 ↑, 내 장비·경험치 ↑)

게임플레이 루프의 골격이 **챕터 진행**으로 정의된다. 챕터가 깊어질수록 적이 강해지지만, **장비·경험치 성장**으로 극복하는 곡선이 게임의 핵심 동기.

**핵심 사양 (초안)**:
- 챕터(Chapter) = 콘텐츠 단위. 각 챕터는 일정 수의 스테이지/웨이브로 구성.
- 챕터 깊이에 따라 적 HP/공격력이 지수적으로 상승.
- 동시에 캐릭터 레벨 / 장비 강화 단계 / 옵션 / 신화 발현이 누적되어 **상대적 파워 곡선이 살짝 상승하는 형태**(0.95→1.0→1.05 지점)를 유지.
- "이 챕터를 못 깰 것 같은데… 한 번만 더 갈고 오면 깰 수 있다" 가 항상 거리감 있는 거리에 있도록 튜닝.
- 시즌제(Part 6)와는 직교한다 — 시즌은 운영 주기, 챕터는 단일플레이 진행도.

**영향**:
- **Part 0**: 핵심 게임플레이 루프(미해결 질문)의 **첫 답안**이 된다. 1세션 = 챕터의 일부 진행 + 인벤토리 정리.
- **Part 1**: 빌드 다양성 위에 **"챕터 진행"이 결정론적 진행의 또 다른 축**으로 추가.
- **Part 2**: 강화 비용 곡선이 챕터 진행 속도와 동조해야 함 — 챕터 깊이별 권장 +N 단계 매트릭스 작성 필요.
- **Part 3**: 챕터별 보상(골드/강화석) 매트릭스 — 운영 핸들로 작동.
- **Part 8**: MVP 우선순위에 "1챕터 + 챕터 보스 1종"이 명시되어야 함. 기존 "일반 사냥 + 일일 던전 1종"보다 챕터 모델이 우선.
