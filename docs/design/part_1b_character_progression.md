# Part 1b. 캐릭터 진행 (XP · 레벨)

> [← Part 1](./part_1_equipment_identity.md) · [README](../README.md) · [다음: Part 2 →](./part_2_item_enhancement.md)
>
> ✦ `direction_v2.md` 2번 항목으로 신설된 파트. 장비 시스템(Part 1·2)과는 **별개의 결정론적 진행 축**을 정의한다.

---

## 1. 핵심 결정

- 캐릭터에는 `level`, `xp`, `next_level_xp` 필드가 존재.
- **적 처치/챕터 클리어 시 XP가 자동 적립**되어 레벨이 오른다. 별도 액션 필요 없음.
- 레벨업 시 **베이스 스탯(HP/공격력/등)이 결정론적으로 상승** — 잭팟 RNG 없음.
- 장비 보너스는 캐릭터 베이스 위에 가산. 두 축이 함께 자라며 챕터 곡선을 따라잡는다.
- **사망/실패해도 XP가 후퇴하지 않는다** — 자부심 보호.
- **시작점 비중**: 캐릭터 50% : 장비 50%. 일찍 너무 많이 캐릭터에 의존하면 장비 자부심이 약해지고, 너무 적으면 갈아도 의미 없어 보인다.

---

## 2. 설계 원칙

- **결정론**: 갈면 무조건 오른다. RNG는 장비/잭팟 영역에만.
- **자동 적립**: 별도 화면 진입·버튼 없이 누적. 인지부담 0.
- **레벨업은 도파민**: 시각·청각으로 분명하게 — 상승한 스탯의 카운트업·이펙트.
- **레벨 캡은 장기 목표**: MVP 30, 출시 60, 시즌 콘텐츠로 +5씩 확장 가능.
- **장비와의 균형**: 한쪽이 과하면 자부심·빌드 다양성 모두 약해진다. 시뮬과 실측으로 50:50을 유지한다.

---

## 3. 구체적 사양

### XP 곡선 (초안)

```
next_level_xp(L) = round(50 × 1.15^L)

L1 → L2:    50 XP
L5 → L6:    101 XP
L10 → L11:  202 XP
L15 → L16:  407 XP
L20 → L21:  818 XP
L25 → L26:  1,645 XP
L30 → L31:  3,313 XP
```

### 레벨업 스탯 상승 (초안)

| 스탯 | 레벨당 | 비고 |
|---|---|---|
| 최대 HP | +10 | 매 레벨 |
| 공격력 | +1 | 매 레벨 |
| 이동속도 | +0.05 | 5 레벨마다 |
| 크리티컬 확률 | +1% | 5 레벨마다 |

### XP 획득 (초안)

| 출처 | XP |
|---|---|
| 일반 적 처치 | 5 |
| 미니보스 처치 | 50 |
| 보스 처치 | 200 |
| 챕터 클리어 보너스 | 챕터 깊이 × 100 |
| 데일리 던전 클리어 | 200 (일일 상한 적용) |

### 데이터 모델

```ts
type CharacterProgress = {
  level: number               // 1 ~ LEVEL_CAP
  xp: number                  // 현재 레벨에 누적된 XP
  next_level_xp: number       // 공식으로 계산된 다음 레벨 요구치
  base_stats: {               // 레벨업마다 재계산
    max_health: number
    attack: number
    move_speed: number
    crit_chance: number
  }
}
```

### 레벨업 트랜잭션 (백엔드)

```
적 처치 이벤트 →
1. SELECT FOR UPDATE on characters
2. xp += enemy.xp_drop
3. while xp >= next_level_xp:
     xp -= next_level_xp
     level += 1
     base_stats 재계산
     next_level_xp = formula(level)
4. audit_log에 LEVELUP 또는 XP_GAIN 기록
5. commit
6. Redis pub/sub: 클라이언트로 LEVELUP 이벤트 푸시
```

레벨업이 한 번에 여러 번 발생할 수 있으니(보스 처치 등), 루프로 처리한다.

### 캐릭터 50% : 장비 50% 비중 가이드

기준 시점: **레벨 30 + 풀 +20 강화 장비 5개 + 신화 1~2개**.

- 캐릭터 레벨 기여: HP +300, 공격력 +30
- 장비 기여 (대략): HP +300, 공격력 +30 (5피스 × 평균값)
- 합산: HP 700~800, 공격력 60~70

이 비중은 **시뮬레이터로 검증**해야 하며, 챕터 보스 HP/공격력은 이 합산을 기준으로 튜닝한다.

## 4. 미해결 질문

- 레벨 캡 정확한 숫자 (MVP 30 가설)
- XP 곡선 계수 1.15가 적절한지 (시뮬 필요)
- 5 레벨마다 부수 스탯 보너스의 정확한 종류·수치
- 레벨업 시 스킬 포인트도 주는가? (미정 — 클래스 시스템과 함께 결정)
- 칭호/도감/페트 같은 보상은 어느 레벨에 어떻게 분배되는가
- 사망 시 XP 패널티 도입 여부 (현재 결정: **없음**)
- 캐릭터 50:50 비중 가정의 검증 방법
