## 1. 핵심 결정

### 5층 아이템 아키텍처

한 아이템은 아래쪽 결정론적 영역과 위쪽 RNG 영역으로 나뉘는 5개 레이어로 구성된다. 아래로 갈수록 진행 보장이 강하고, 위로 갈수록 잭팟의 기쁨이 크다.

| 레이어 | 내용 | 성격 |
|---|---|---|
| 5. 신화 옵션 | 시즌 잭팟, 빌드 정의 효과 | 메가 잭팟 (월·시즌 단위) |
| 4. 옵션 라인 × 3 | 리롤 가능, 잠금 가능 | 소형 잭팟 (분·일 단위) |
| 3. 강화 +16~+25 | RNG, 천장 보장 | 진행 + 잭팟 혼합 |
| 2. 강화 +0~+15 | 결정론적, 자원 = 100% 성공 | 순수 진행 |
| 1. 베이스 스탯 | 드랍 즉시 확정 | 회수 가치 |

## 2. 설계 원칙

### 실패 처리 정책

실패 시 단계는 유지되고 자원만 소모한다. 추가로 보호 아이템 옵션을 두어 자원 의사결정 깊이를 남긴다.

- **기본**: 단계 유지 + 강화석만 소모
- **보호 아이템 사용 시**: 성공률 +5%, 실패 시 마일리지 2배 등 추가 효과
- **절대 도입 금지**: 파괴, 단계 하락 (현대 잭팟 게임에 부적합)

### UX 노출 규칙

천장 시스템은 플레이어에게 보여줘야 작동한다. 다음 정보를 카드 UI에 항상 노출:

- 현재 누적 실패 횟수
- 다음 시도 실제 성공률 (소프트 천장 반영 후)
- 하드 천장까지 남은 횟수
- 기본 확률은 흐릿하게 (낮음/중간/높음 라벨), 정확한 % 별도 페이지에 노출 (한국 게임산업법 확률 공시 의무)

## 3. 구체적 사양

### 강화 확률 공식

기본 성공률은 +16부터 지수적으로 감소한다.

```
p_base(level) = 0.50 × 0.85^(level - 16)

+16: 50.0%   +21: 22.2%
+17: 42.5%   +22: 18.8%
+18: 36.1%   +23: 16.0%
+19: 30.7%   +24: 13.6%
+20: 26.1%   +25: 11.6%
```

소프트 천장은 5회 연속 실패부터 회당 +5%p씩 누적, 하드 천장은 20회 도달 시 다음 시도 100% 보장이다.

```
소프트 천장:
  N회 연속 실패 시
  p_actual = min(1.0, p_base + max(0, N - 5) × 0.05)

하드 천장:
  N = 20 도달 시 다음 시도 100% 성공
```

### 신화 옵션 마일리지 공식

```
base_rate = 0.005  (0.5%)
실패 시마다 mileage += 1
mileage ≥ 200 도달 시 다음 시도 발현 보장
(옵션) mileage ≥ 100 시 발현 확률 5%로 상승
```

### 챕터 진행 ↔ 강화 단계 동조 매트릭스 (✦ 초안)

> 챕터가 깊어질수록 적이 강해지지만, **권장 강화 단계도 동조해 상승**한다. 플레이어는 "한 번만 더 갈면 깰 수 있다" 거리감을 항상 느낀다.

| 챕터 | 권장 캐릭터 레벨 | 권장 평균 +단계 | 신화 보유 기대 |
|---|---|---|---|
| 1 | 1~10 | +0~+5 | 0종 |
| 2 | 10~15 | +5~+10 | 0종 |
| 3 | 15~20 | +10~+13 | 0~1종 |
| 4 | 20~25 | +13~+15 (결정론 끝) | 1종 |
| 5 | 25~30 | +15~+18 (천장 시작) | 1~2종 |
| 6+ | 30+ (시즌·메타 진행) | +18~+25 (천장 풀가동) | 2종+ |

이 매트릭스는 **시뮬레이터로 검증** 필요. 챕터 보스 HP/공격력은 권장 강화 단계 + 권장 레벨의 합산 파워를 기준으로 튜닝한다 (보스 권장 클리어 파워의 0.95~1.05 배 권장 — 너무 쉽지도, 너무 어렵지도 않게).
