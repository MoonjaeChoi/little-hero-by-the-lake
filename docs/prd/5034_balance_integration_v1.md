## 2. 메이플 키우기 핵심 시스템 (조사)

### 2.1 슬롯 강화 (스타포스)

- 0~25성, 13→14성부터 하락, 15→16성부터 파괴 가능
- 잠재 옵션 unlock: 3성 (메이플 본판)
- 단계별 비용 비선형 ↑, 성공률 ↓

### 2.2 데미지 비율

```
데미지 18% = 최대뎀 10% = 공속 5%   (유니크 잠재 환산)
데미지 14% = 최대뎀 7%               (레전 유물 환산)
```

### 2.3 직업별 시너지

- 근접 직업 = 안정성 (탱커형)
- 마법사 = 광역 사냥 (DPS형)
- 궁수 = 원거리 + 균형
- 계정 단위 버프 (여러 직업 함께 키우기 권장)

## 3. 통합 밸런스 재설계 (5034)

### 3.1 권장 진행 매트릭스 (챕터 × 캐릭터 × 강화)

| 챕터 | 권장 Lv | 무기 +N | 슬롯 ⭐ | 비고 |
|---|---|---|---|---|
| **1~5** (튜토리얼) | L1~L13 | +0~+3 | ⭐0 | starter weapon 만 |
| **6~10** (티어 1) | L13~L20 | +5~+8 | ⭐0~⭐3 | 마법의돌 첫 unlock |
| **11~15** (자연) | L20~L25 | +10~+12 | ⭐3~⭐7 | 가챠 Rare 진입 |
| **16~20** (티어 2) | L25~L32 | +13~+15 | ⭐7~⭐10 | Epic 가챠 가능 |
| **21~25** (동물·문명) | L32~L37 | +16~+18 | ⭐10~⭐13 | +16+ 마법 결정 도입 |
| **26~30** (티어 3) | L37~L43 | +19~+22 | ⭐13~⭐16 | Legendary 가챠 진입 |
| **31~35** (환상 정점) | L43~L50 | +23~+25 | ⭐16~⭐20 | Mythic 마일리지 + 신화 unlock |

> 챕터 N 진입 시 권장 ⭐ = `min(N/2 + 0, 20)` (대략 1챕터당 +0.5⭐).

### 3.2 슬롯 강화 곡선 재조정 옵션

**현재 (5033.4 적용)**:
```
⭐0=0% / ⭐5=30% / ⭐10=60% / ⭐15=100% / ⭐20=200%
```

**옵션 A — 현재 유지**: 직관적 (⭐15 = 2배). 단 권장 ⭐ 매트릭스와 정합 검증 필요.

**옵션 B — 메이플 정합 강화**: ⭐15 → 150% (1.5배 더 강화), ⭐20 → 300% (3배). 캐시 강화 유인.

**옵션 C — 곡선 평탄화**: ⭐0~⭐10 빠르게 (선형), ⭐10~⭐20 느림 (지수). 초보 친화 + 캐시 영역 분리.

### 3.3 무기 강화 +N 곡선 (`equipment_v1.md` 답습)

- +0~+15: 결정론 100%
- +16~+25: RNG (P_FLOOR 30% 동결)
- +N → baseStats × (1 + N×3%) ? 또는 attackConfig.damage × (1 + N×4%) ?

> **재설계 결정 사항** — D5 옵션:
> - D5-A: +N → attackConfig.damage 곱셈 (+25 = 2배)
> - D5-B: +N → 모든 stat 곱셈 (+25 = 1.75배 균등)
> - D5-C: +N → STR 코어 추가 (+25 = +50 STR)

### 3.4 직업별 시너지 강화 (메이플 정합)

**현재 WeaponClassBonus**:
- 전사 + 검·둔기 → +Dmg 10%
- 궁수 + 활·단검 → +AS 5%
- 마법사 + 지팡이·완드 → +MagicDmg 10%

**5034 강화안 (옵션 D)**:

**D6-A — 단순 강화**:
- 전사 +Dmg 15% / 궁수 +AS 8% / 마법사 +MagicDmg 15%

**D6-B — 직업별 특수 스탯 곡선** (메이플 정합):
- 전사: STR 보너스 +20%, 보스 데미지 +10% (탱커형)
- 궁수: AGI 보너스 +20%, 크리 확률 +10% (균형)
- 마법사: WIS 보너스 +20%, 광역 데미지 +15% (DPS형)

**D6-C — 직업 시너지 매트릭스 (계정 단위 버프)**:
- 3 직업 모두 L30 도달 → 계정 +5% 모든 데미지
- 3 직업 모두 챕터 35 클리어 → 계정 +10%
- 메이플 답습이지만 LittleHero 단일 캐릭터 게임 톤과 약간 어긋남

### 3.5 DPS Check 통합 수식 (50:50 검증)

```
DPS_target(N) = (BossHP(N) / TTK_target) × ArmorMul

BossHP(N) = 950 × 1.10^(N-1)
TTK_target = 30~60s (보스 도파민 영역)
ArmorMul = 1 / (1 - DamageReduction%)

DPS_player(L, N, ⭐, +N, affix, mythic) =
  (CharacterBase + L × atkPerLv) × StarMul(⭐) × WeaponMul(+N)
  × (1 + AdditiveDmg) × (1 + FinalDmg)
  × (1 + CritChance × (CritDmg-1))
```

5034 검증: **DPS_player ≥ DPS_target × 1.0** (권장 진행 시), DPS_player ≥ DPS_target × 0.7 (권장 미달 시 도전 가능).

### 3.6 캐시 vs 무료 진행 비율

- **무료 진행**: 챕터 35 = ~30~40 시간 (idle 게임 표준)
- **캐시 가속**: 별빛 ⋆ 캐시 → 가챠 + 마법의돌 조각 → 슬롯 강화 빠른 진행
- **권장 비율**: 무료 35 챕터 가능, 캐시 진행 시 50% 시간 단축 (메이플 답습)
