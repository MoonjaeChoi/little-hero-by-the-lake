## 1. 핵심 결정

### 챕터 ↔ 시즌의 관계 (✦)

두 축은 **직교**한다. 헷갈리지 말 것:

- **챕터**: 단일 플레이어의 콘텐츠 진행도. 깊이가 늘어나며 적이 강해지고 보상이 커진다 (Part 0·Part 2·Part 8).
- **시즌**: 운영 주기. 12주마다 새 캐릭터 풀(Season Realm)이 시작되고 시즌 한정 신화·코스메틱이 추가된다.

같은 챕터 1을 Eternal Realm에서도, Season Realm에서도 진행할 수 있다. 시즌 시작 시 시즌 캐릭터의 챕터 진행도는 0부터 시작.

### 듀얼 실현 모델

긴 호흡 잭팟 게임에서 시즌제는 한 가지 결정을 강요한다 — **노력의 결과를 리셋할 것인가**. 답은 **둘 다 두는 것**이다.

**Eternal Realm**:
- 영구 캐릭터 — 절대 리셋 없음
- 모든 신화 옵션 · 세트 효과 영구 보존
- 베테랑의 꿈의 아이템 보호 영역

**Season Realm**:
- 시즌마다 새 캐릭터 시작
- 가속된 진행 (메인 대비 1.5~2배 경험치)
- 시즌 한정 신화 옵션
- 고유 시즌 보상 (코스메틱, 칭호)

플레이어는 두 실현을 동시에 가질 수 있고, **시즌 종료 시 시즌 캐릭터 + 인벤토리는 메인으로 자동 병합**된다.

## 2. 설계 원칙

### 12주 시즌 라이프사이클

| 페이즈 | 주차 | 주요 운영 활동 |
|---|---|---|
| 런칭 | 1~4주 | 신화 5종 추가, 시즌 보스 첫 컷, 레이스 활성 |
| 정착 | 5~8주 | 커뮤니티 빌드 형성, 밸런스 미세조정 |
| 캐치업 | 9~11주 | 신규 부스트팩, 2배 드랍률, 합류 적정 시점 |
| 병합 | 12주 | 시즌 보상 코스메틱 지급, 메인 실현 이전 |

### 5종 캐치업 메커니즘

1. **스마트 루트** — 드롭 알고리즘이 캐릭터가 부족한 슬롯 우선 채움. **지표상 가장 효과 큰 캐치업 도구**.
2. **계정 영구 진행도** — 일부 도전과제, 코덱스 발견은 계정 영구 자산. 다음 시즌에도 따라옴.
3. **1회용 부스트 티켓** — 시즌당 계정 1개. 중반 컨텐츠 진입 직전까지 끌어올림 (엔드게임까지는 아님).
4. **복귀자 환영 이벤트** — 30일+ 미접속 후 자동 트리거. 변경사항 가이드 + 단축 컨텐츠.
5. **서버 전체 부스트 이벤트** — 9~11주차 운영팀 트리거. 신규/복귀와 베테랑 모두 윈윈.

### 베테랑의 함정 회피 — 가장 흔한 실수

운영 1~2년 차에 가장 자주 깨지는 패턴: **시즌 한정 신화가 너무 강력해서 메인 실현으로 안 가져오면 손해**가 되는 경우. 이 순간 시즌제가 의무가 되고 베테랑이 이탈한다.

- 시즌 한정 신화 = **다양성**, 절대 ≠ 파워
- 기존 빌드보다 명백히 강하면 안 됨
- 시즌 종료 시 풀 합류 시점에 가벼운 너프 가능
- 시즌 보상은 **코스메틱 + 명예** 영역에만 (칭호, 펫, 마운트, 프레임)
- 강력한 영구 효과를 시즌 보상으로 주면 결손감 → 신뢰 파괴

## 3. 구체적 사양

### 데이터 모델

```ts
type Character = {
  id: string
  account_id: string
  realm: 'eternal' | 'season'
  season_id: number | null     // realm='season'일 때만 값
  // ... 나머지
}

type Item = {
  id: string
  owner_character_id: string
  // 시즌 종료 시 owner가 메인 캐릭터로 변경됨
}
```

**쿼리 패턴**:
- `realm` 필드가 모든 쿼리의 첫 `WHERE` 절에 포함
- 처음부터 인덱스에 포함시켜 둘 것
