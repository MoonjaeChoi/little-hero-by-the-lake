## 1. 핵심 결정

### MVP에 반드시 포함할 것

코어 강화 루프 + 캐릭터 진행 + 챕터 진행 곡선이 작동하는지 검증하는 게 MVP의 목적이다. 시즌제·거래소·길드는 모두 후속 단계.

- 1개 클래스 + 1개 무기 종류
- 5개 슬롯 장비 시스템 (무기, 방어구 2종, 장신구 2종)
- 강화 시스템 +0~+15 (결정론) + +16~+20 (천장 포함)
- 옵션 라인 3개 + 리롤 + 잠금
- 세트 효과 3종 (각 4피스)
- 신화 옵션 10종 (시즌 한정 미포함)
- ✦ **1챕터 + 챕터 보스 1종** + 적 강화 곡선 (챕터 깊이별 HP/공격 지수)
- ✦ **캐릭터 레벨 1 ~ 30** + XP 자동 적립 + 레벨업 베이스 스탯 상승 (Part 1b)
- 일반 사냥 + 일일 던전 1종
- ✦ 인벤토리 + 아이템 카드 UI (**모바일만**)
- 재화 3종 (골드, 강화석, 리롤석)
- 최소 어드민 도구 (유저 검색, 재화 지급)

### MVP에서 제외할 것

- 시즌제 (단일 실현으로 시작, 후속에서 도입)
- 신화 옵션의 시즌 회전
- 거래소 (1.x 패치에서 도입)
- 캐치업 메커니즘 (스마트 루트 외)
- 길드 / 사회 시스템
- PvP
- 도감 / 코덱스 (간이 버전만)
- 결제 시스템 (CBT까지는 가짜 재화로)

## 2. 설계 원칙

### 권장 개발 단계

| Phase | 기간 | 목표 |
|---|---|---|
| 1 | 12주 | 코어 강화 루프 + 카드 UI 검증 (내부 알파) |
| 2 | 8주 | 옵션·세트·신화 시스템 + 콘텐츠 추가 |
| 3 | 8주 | 운영 도구 + 안정화 + 부하 테스트 |
| 4 | 4주 | 클로즈드 베타 |
| 출시 | — | 단일 실현 출시, 시즌제는 첫 분기 후 도입 |

## 3. 구체적 사양

### 초기 핵심 검증 지표

- D1 잔존율 (목표 50%+)
- D7 잔존율 (목표 25%+)
- 세션당 강화 시도 평균
- 천장 도달까지 평균 시도 횟수 (공식 검증)
- 신화 발현 시점의 세션 만족도 (설문)
- ✦ **챕터 1 클리어까지 평균 플레이 시간** + 분포 (목표 6~8시간, 너무 짧으면 자부심 결여)
- ✦ **챕터 1 보스 클리어 시점의 평균 캐릭터 레벨** + **장비 +N 단계** (50:50 비중 검증)
- CS 인입량 / 유저 (운영 부담 측정)

### 위험 요소와 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 천장 공식이 너무 빡빡 | 이탈 | Phase 1 알파에서 시뮬레이터 + 실제 플레이로 검증 |
| 신화 효과 밸런스 붕괴 | 메타 단조화 | archetype별 분포 강제 + 출시 후 즉시 너프 가능 구조 |
| 모바일 UI가 PC와 격차 | 모바일 이탈 | 단일 컴포넌트 공유, 모바일 우선 디자인 |
| 어드민 미비로 운영 사고 | 데이터 손상 | 출시 전 모든 CS 시나리오 어드민에서 처리 가능 확인 |
| P2W 압력 누적 | 장기 신뢰 파괴 | 캐시샵 카탈로그 출시 전 외부 검토 |
