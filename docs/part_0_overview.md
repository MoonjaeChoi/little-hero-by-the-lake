## 1. 핵심 결정

### 핵심 정체성
- **플랫폼**: PC + 모바일 코어 (긴 세션 지향)
- **핵심 가치**: 장기 목표 + 잭팟 추구
- **장르**: 빌드 다양성 중심의 ARPG
- **영감**: 메이플스토리의 깊이 + 디아블로의 빌드 다양성 + 탕탕특공대의 진행 명확성

### 타겟 유저
- **주 타겟**: 중간 코어 ARPG 유저, 시즌 메타 추구, 한 캐릭터에 수십~수백 시간 투자 의향
- **부 타겟**: 라이트 모바일 유저, 짧은 세션이지만 누적 진행 즐기는 유형
- **배제 타겟**: 1세션 30분 미만의 캐주얼 매치 게이머 (탕탕특공대 직접 경쟁 회피)

## 2. 설계 원칙

세 레퍼런스 게임의 좋은 점만 차용하되, 각각의 약점을 시스템적으로 차단하는 위치를 잡는다.

| 항목 | 차용 | 회피 |
|---|---|---|
| 메이플스토리 | 다층 RNG의 잭팟 깊이 | 신규 진입장벽 누적, 좌절 누적 |
| 디아블로 | 빌드 다양성, 시즌 회전, 데이터 주도 콘텐츠 | 한국 정서 대비 액션 위주 |
| 탕탕특공대 | 진행 명확성, 모바일 친화 UI | 낮은 깊이, 짧은 수명 |
